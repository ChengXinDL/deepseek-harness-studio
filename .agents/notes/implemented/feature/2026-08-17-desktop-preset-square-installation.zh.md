# Agent Note: Desktop Preset 广场安装

Status: implemented

[English](2026-08-17-desktop-preset-square-installation.md) | 中文

## Problem

Agent Preset 已经允许用户选择新会话的组合，但已交付的 Desktop 只提供本地清单与创作控制。发现社区 Preset 仍需离开应用、理解磁盘目录并手动复制可执行配置。把 Preset 当成普通插件也会造成误导：Preset 决定 Agent、插件、工具与提示词组合，而插件安装改变的是正在运行的 Host 包图。

## Decision

Preset 广场是与插件中心、插件发现平级的一级页面，由同一个客户端组件提供相互独立的“广场”和“已安装”视图。“广场”读取完整公开列表，在内存中即时搜索，保留服务端拥有的“下载最多/最新发布”顺序，并打开原生详情；“已安装”在公开服务失败时仍可独立使用本地 Preset 清单。浏览器开发桥只提供确定的只读条目；安装、删除和会话选择仍仅在 Desktop 中开放。

广场合并两种明确的目录来源。**赋范官方**表示由赋范桌面端开发团队维护、随应用内置的内容，不代表 DeepSeek Harness 官方。只读 Desktop 资源交付六套精简能力包：AI WebApp、PPT Office、视频生成、内容工厂、AI 报表和飞书数字员工。社区条目继续来自固定服务。两条路径复用同一预览与 Host 导入器，赋范能力包仍故意落到用户根目录，以保持可删除和可重装。

Desktop 主进程拥有指向固定 `https://www.dshdesktop.com/preset/` 源的全部网络请求。严格合同拒绝未知响应结构、非 HTTPS 或外域产物 URL、超大元数据、非法标识与格式错误的哈希。交给 Host 前，Desktop 会重新解析详情，以禁止重定向的方式下载受限 `.dshpreset` 产物，校验声明字节数与 SHA-256，然后通过专用 loopback 二进制入口发送内容。Renderer 只能选择已发布 slug 与校验后的本地目标 id，不能提供来源、下载 URL、文件系统路径或压缩包字节。

Host 按压缩大小、展开大小、单文件大小与文件数量限制预览和安装压缩包。它拒绝绝对路径、父级穿越、盘符、反斜杠、NUL 与布局外路径；要求版本化 `dsh-preset` manifest 和 `preset/agent.cordis.yml`；并扫描绝对路径、疑似密钥与 DSH 版本差异警告。安装先写入可写用户 Preset 根目录下的临时目录，用现有 Preset 扫描器验证结果，再原子重命名到目标位置。已有 id（包括系统 id）永远不会被覆盖。

安装或删除后，同一界面重新读取 Host 实时清单。系统 Preset 保持可见且受保护；只有用户 Preset 提供删除。“用于新会话”会让 Workspace runtime 复用或创建一个空白会话，通过 `agentPreset.select` 切换该会话，更新会话投影并打开它，最后关闭一级目录页面。既有对话永远不会被重新组合。

## Alternatives considered

**在浏览器中打开公开 Preset 网站。** 这能避免原生界面开发，却无法提供一键校验安装、本地状态、删除和直接进入新会话的路径。

**让 Renderer 下载并解压。** 这会把网络与文件系统权限交给最不可信的进程，并重复 Host 已拥有的 Preset 校验规则。

**接受任意 URL 或本地压缩包路径。** 这会把第一版扩大成通用包导入器，破坏固定来源与已收录条目的边界。已交付界面只安装从 Preset 广场重新解析出的产物。

**覆盖已有 Preset id。** 静默替换可能改变未来 Agent 组合，也可能遮蔽系统 Preset。冲突会阻止安装，直到用户选择另一个合法 id。

**将 Preset 应用到当前对话。** 已开始对话的历史与工具调用属于原始组合，因此该动作只面向空白会话，并复用现有逐会话 Preset 不变量。

## Verification

合同测试覆盖合法公开条目，以及外域 URL、错误标识、哈希和响应结构的拒绝。Desktop 客户端测试覆盖列表/详情读取、校验预览/安装、摘要不匹配、重定向拒绝与 Host 不可用。Host 测试覆盖压缩包路径穿越、解压限制、必需布局、警告、冲突、原子安装与专用二进制入口。客户端测试覆盖本地即时搜索、显式排序、预览确认、安装后刷新、仅用户可删除，以及操作后停留在 Preset 页面。

## Consequences

用户无需编辑文件即可发现、检查、安装、管理并使用赋范维护或社区 Preset，而当前 Host 清单仍是实际已安装状态的权威。社区安装在预览与确认之间会再次下载，以便重新校验当前发布元数据；内置安装则重新生成同一份确定归档。本版明确不包含发布、账号、评分、自动更新和任意来源导入；增加这些能力需要新的权限与信任决策。
